# 📊 Kubernetes Platform & Monitoring Stack

This directory contains the core platform services deployed inside our **Talos Linux Kubernetes Cluster**. It configures automatic cluster logging and application-level distributed tracing without altering any application code, utilizing **Grafana Alloy** and **eBPF-powered Grafana Beyla**.

---

## 🏗️ Architecture Components

*   **Grafana Web UI:** The central visualization pane and alerting system (`grafana.yaml`).
*   **Grafana Alloy:** Distributed log collector running as a cluster DaemonSet (`grafana-alloy.yaml`).
*   **Grafana Beyla:** Kernel-level eBPF network auto-instrumentation collector (`grafana-beyla.yaml`).
*   **Grafana Loki:** Centralized log stream database backend (`central-monitoring.yaml`).
*   **Grafana Tempo:** Distributed trace timeline storage engine (`central-monitoring.yaml`).

---

## 🚀 Deployment Order

To deploy or sync updates to the monitoring stack, execute the following commands in sequence from the root of your workspace:

```bash
# 1. Create the dedicated monitoring namespace and cluster roles
kubectl apply -f platform/namespace.yaml

# 2. Spin up the localized Loki and Tempo storage backends
kubectl apply -f platform/central-monitoring.yaml

# 3. Deploy the Grafana Web dashboard interface (pre-configured with log-to-trace link mappings)
kubectl apply -f platform/grafana.yaml

# 4. Initialize collectors across all Talos cluster nodes
kubectl apply -f platform/grafana-alloy.yaml
kubectl apply -f platform/grafana-beyla.yaml
```

## 🔍 How to View Traces & Logs

1. Open your web browser and navigate to the web panel:
   ```text
   http://<ANY_TALOS_VM_IP>:32000
   ```
2. Log in with the default credentials:
   * **Användarnamn (Username):** `admin`
   * **Lösenord (Password):** `admin`
3. Head over to the **Explore** tab on the left sidebar.
4. Select **Loki** as your datasource to review live application logs.
5. Expand any incoming application log message containing an active trace reference. Click the blue **`TraceID`** button to split the window and explore the multi-service network dependency span map generated by Tempo!

## 🛠️ Diagnostics & Verification

If logs or traces are missing, check the health of the collector daemons:
```bash
# Verify all pods are running successfully
kubectl get pods -n monitoring

# Tail live telemetry logs from Grafana Alloy
kubectl logs -n monitoring -l app=grafana-alloy --tail=50
```
